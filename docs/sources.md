# Text source

The initial corpus is George Long's public-domain translation of *Meditations* from Project Gutenberg eBook 2680.

- Source page: <https://www.gutenberg.org/ebooks/2680>
- Plain text: <https://www.gutenberg.org/files/2680/2680-0.txt>
- Translator: George Long

Run `npm run fetch-source` to refresh `data/source/meditations-long.txt`, then `npm run parse` to regenerate the structured pages. Modern copyrighted translations are not bundled; the JSON schema leaves room for a licensed modern translation or a separately generated paraphrase.
